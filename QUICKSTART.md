# Quick start

```bash
./scripts/setup.sh
./scripts/start-ui.sh
```

Open http://127.0.0.1:3920

1. **Settings** → paste **your** API key → Save → Test model  
2. **Connections** → Enable Chrome control → sign into Instagram & LinkedIn  
3. Add ideas → Generate draft → Approve → **Post now**

No keys or accounts are included in the download.
